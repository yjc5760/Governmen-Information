SEARCH

四個欄位是 AND——填幾個就要同時成立。標案 API 一次只能用一個條件查，而且沒有機關查詢端點，所以程式會挑選擇性最高的當主查詢（機關索引唯一命中 › 統一編號 › 廠商名稱 › 標案名稱），其餘在前端篩。畫面上會標明主查詢是哪個、掃了多少筆，別把部分結果當成全部。

proxy 沒有回應

這頁需要本機 proxy。開啟終端機／命令提示字元，切到 proxy 資料夾執行 npm start，再按下方重試。

LIVE SEARCH

直接查政府電子採購網，只回傳尚未截止的案子，清單就帶截止日與預算。

WATCHLIST

關鍵字監看

AGENCY INSIGHT

選一個機關，看它歷年發包給誰

選定後會直接向 API 抓該機關的全期間公告，不受同步天數限制。

下方是已認識的機關——標案 API 沒有「用機關名稱查機關」的端點，機關只能從抓下來的公告裡累積。同步過的公告、查詢結果、開過的標案都會自動加進來，且不會隨公告快取被裁掉。
